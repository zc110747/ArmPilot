### 本轮新增（真实硬件路径）
- `bsp/adc.c/.h`：单 ADC，AVCC / 预分频128 / 10-bit，阻塞读 `adc_read(ch)`（A0..A3=PC0..PC3）。
- `bsp/ir.c/.h`：NEC 解码，PD2=INT0 双边沿 + Timer0/64(4µs/tick)；状态机收 32-bit，校验

- `core/joystick.c/.h`：`joystick_scan()` 每主循环读 4 轴→`joystick_delta(id,raw)`（阈值同原

- `core/ir_ctrl.c/.h`：`ir_ctrl_poll()` 每主循环 `ir_get_code`→匹配 8 键表→`arm_nudge`；
  键表（左/右/数字2/8/上/下/数字4/6 → 底座/左/右/夹取 ±2）与原 Arduino 完全一致。
- `core/cmd.c` 新增 `JOYHW ON|OFF`、`IRHW ON|OFF`、`ADC`（打印 A0..A3 原始值）。

### 🔴 关键修复：AVR .data 字符串导致栈溢出（固件命令下发即复位/乱码）
- 症状：被动监听开机正常（单条 banner），但 `host_verify.py` 批量下发指令时反复重启、
  回显乱码（`STATUS S6=0(H)`、`ERR UNKNOWN =90(H)`）。
- 根因：`avr-gcc` **默认把所有字符串字面量拷贝进 `.data`（RAM）**。help 文本 + 状态/错误串
  约 **1348 B** 进 `.data` → `.data`=1610、`.bss`=332、RAM 占 1942/2048，**栈仅 ~97 B**；
  而 `uart_printf` 的 160 B 栈缓冲在命令处理时把栈顶砸进 `.bss` → 复位/乱码。
- 修复（务必延续）：
  1. `uart.c` 改为 flash 版：`uart_puts(PGM_P)` 用 `pgm_read_byte`；`uart_printf(PGM_P)` 用
     `vsnprintf_P`；内部栈缓冲从 160→96 B。
  2. 所有调用点字面量包 `PSTR("...")`（main/arm_control/cmd/ir_ctrl）。
  3. 常量表 `IR_TAB`/`TAB`/`J_CH`/`J_ID`/`ids` 全部 `PROGMEM` + `pgm_read_*`（IR 键名用内联
     `char name[12]` 存 flash，避免 PSTR 不能用于静态聚合初始化的问题）。
- 效果：`.data` **1610 → 94 B**，RAM ≈ 426 B，**栈余量 ≈ 1366 B**，零警告构建，
  FLASH=9626B(29.8%)。重烧 COM4 后 `host_verify.py` **46/46 PASS 且不再复位/乱码**。
- 诊断手法（可复用）：`avr-size -A` 看 .data/.bss；`avr-nm -S --size-sort` 找大符号；
  `avr-objdump -s -j .data` 直接看 .data 内容确认字符串是否在 RAM。

### 验证
- 零警告构建；`avrdude` 烧录 COM4 成功（9626 B verified）。
- `tools/host_verify.py COM4 9600`：**46/46 PASS**（单控/钳位/非法id/左右同时/超3电机/组合/
  简写/自变化冻结/JOY单轴+整帧/IR 8键±2/未知码/JOYHW+IRHW ON-OFF/ADC）。

## 续2：红外动作序列 + 主循环去忙等 + 一键编译下载（晚）

### 用户新需求（6 条）
1. 红外按钮 1/3/7/9 各定义一套动作（~15s，我设计），中间 5s 暂停，循环执行。
2. 每次移动到位后到下次指令要有间隔，确保达到位置。
3. 收到 5 键或摇杆指令则循环结束。
4. 一套任务执行中收到另一套任务，直接停止、从另一套开头执行。
5. 主循环 20ms 延时太久了，不要延时、直接循环处理，需延时按 tick 手动检测。
6. 项目实现一键编译+下载脚本。

### 实现
- `bsp/systick.c/.h`：Timer2 CTC（/64, OCR2A=249→1ms）提供 `systick_ms()` 单调时钟。
- `core/main.cpp`：去掉 `_delay_ms(20)`；循环自由运行，仅 `arm_tick`+`joystick_scan` 按 20ms
  tick 节拍、`led` 按 500ms tick 翻转；`ir_seq_tick()` 每循环调用（即时响应停止/切换）。
- `core/ir_seq.c/.h`：4 套关键帧表（PROGMEM，各 7 帧含 1 个 5s 暂停帧，在强制范围内安全姿态）。
  `ir_seq_tick()`：仅"移动到位(`arm_all_reached`) 且 hold_ms 已到"才进下一帧（满足需求2）；
  检测到摇杆边沿(`joystick_consume_input`)→停止（需求3）；另一套按钮→`ir_seq_trigger` 从头
  （需求4）；循环执行（需求1）。`arm_all_reached()` 加在 `arm_control.c`。
- `core/joystick.c`：加 `g_moved` 边沿标志 + `joystick_consume_input()`（需求3 的摇杆检测）。
- `core/ir_ctrl.c/.h`：IR_TAB 扩到 13 项（8 微调 + 4 动作集 + 1 停止），加 op 字段；
  新增 `ir_ctrl_dispatch(code)`（硬件 poll 与串口 `IR <hex>` 共用，保证一致）。
  新 NEC 码（地址 0xC1/0xC3/0xC5/0xC7/0xC9，避开原 8 键）：1=0xC13E01FE, 3=0xC33C03FC,
  7=0xC73807F8, 9=0xC93609F6, 5=0xC53A05FA（均已过 NEC 反码校验）。
- `core/cmd.c`：`SEQ 1|3|7|9` / `SEQ STOP` / `SEQ ?` 命令；`JOY` 指令调用 `ir_seq_stop()`
  （串口摇杆=摇杆指令，满足需求3）；串口 `IR <hex>` 改走 `ir_ctrl_dispatch`。
- `scripts/build_upload.bat`：先 call build.bat 再 avrdude 烧录 COM4（可 `build_upload.bat COM3`
  指定端口），满足需求6。
