     舵机命名 ≠ 运动学角色、建目录先探针、git push 由用户执行

   - 验收节奏 + 当前基线（vitest 233 · e2e 52 · go test 56）

   - 沙箱工具链环境坑

4. 本日志。

### 关键判断

若复制进工程级会产生**两份真相源**，改一处漏一处。故工程级只做导航 + 铁律，
正文指向用户级权威文件。
